# M3秋2026 巡回マップ

M3-2026秋（2026年10月25日・東京流通センター）で回りたいブースを会場マップに配置し、優先度に合わせた巡回ルートを表示するスマホ向けページです。

| ページ | 内容 |
|---|---|
| [`index.html`](./index.html) | ブランク版。ブースは入っていません。ブース番号を入力して自分のリストを作れます。 |
| [`my/index.html`](./my/index.html) | 作者が回る予定の18ブース入り版。 |

## 機能

- 第一展示場（2F）・第二展示場1F・2Fの3つの地図を切り替え、ブースに巡回順の番号を表示
- ブースごとに「最優先・優先・余裕があれば」を設定
- 「優先度順」「最短距離」の2種類のルート計算（建物の移動はなるべく少なくなるよう計算）
- スタート地点を「第一展示場 入口（開場時の南側入口）」と「第二展示場 1F入口」から選択
- 訪問済みチェックでルートを再計算
- ブース番号（例: `コ-21b`、`T-15ab`）でブースを追加、「リストから外す」で削除

設定はブラウザの localStorage に保存されます（ブランク版と18ブース入り版は別々に保存）。

## 注意

- 机の配置は M3 Webカタログ（catalog.m3net.jp/2026f）の会場マップをもとにしています。入口・エスカレーターの位置と距離は目安です。
- 非公式のファンメイドツールです。
