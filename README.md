# M3秋2026 巡回マップ

M3-2026秋（2026年10月25日・東京流通センター）で回りたいブースを会場マップに配置し、優先順位に合わせた巡回ルートを表示するスマホ向けページです。

| ページ | 内容 |
|---|---|
| [`index.html`](./index.html) | ブランク版。ブースは入っていません。ブース番号を入力して自分のリストを作れます。 |
| [`my/index.html`](./my/index.html) | 作者が回る予定の18ブース入り版。 |

## 機能

- 第一展示場（2F）・第二展示場1F・2Fの3つの地図を切り替え、ブースに巡回順の番号を表示
- 優先順位をドラッグ（またはキーボードの↑↓）で並べ替え。「優先順位を並べ替える」ボタン（またはURL末尾の `#rank`）で開くポップアップで操作
  - 初期設定は「建物ごと」。第一展示場と第二展示場（1F・2F）を別々に並べ、スタート地点の建物を回り終えてから、もう一方へ1回だけ移動。第二展示場は1階と2階を行き来しないよう、1位のブースがある階を先に回り切ってからもう一方の階へ移る
  - 「まとめて」にすると全ブースを1つのリストで並べる（建物の行き来が増えることがある）
  - 「最短距離」で「後回し」をオフにしたときは、1位以外の順位を使わない（画面に案内を表示）
- ルートは3種類
  - 最短距離（初期設定）: 優先順位1位のブースから回り始め、そこから最短の順に回る。初期設定では上位5位までを先に回り、6位以下はそのあとに回る（「後回し」の設定でオフにしたり、何位までを先に回るかを変えたりできる）
  - 近くを寄り道: 上位3件の中から近いブースを先に回る。どのブースも本来の順位から2つより後ろには下がらない
  - 優先順位どおり
- 第一展示場は入口と出口が別。第二展示場へは北側の出口から出る。開場直後は南入口からのみ入場でき、「午後」に切り替えると北入口も使うルートを計算
- 第二展示場1Fも入口と出口が別（出口は入口のすぐ北側）。第一展示場へ戻るときは出口から出るルートを計算
- 右上のボタンでライト／ダーク表示を切り替え（ブラウザに記憶。未設定なら端末の設定に従う）
- 訪問済みチェックでルートを再計算
- ブース番号（例: `コ-21b`、`T-15ab`）でブースを追加、「外す」で削除

## データの保存

優先順位・訪問済み・追加したブースは、各端末のブラウザの localStorage に保存されます。Cookie は使っておらず、サーバーにも送信しません。そのため、複数の人が使ってもデータが混ざったり上書きされたりすることはありません。

- ブランク版と18ブース入り版は別々のキーに保存されます。
- 同じブラウザで複数のタブを開いた場合は、最後に保存した内容がほかのタブにも反映されます（古いタブで上書きしないようにしています）。
- ブラウザのサイトデータを消去すると、保存内容も消えます。
